太阳渐变 · 四个时段共用的一个恒定元素
暖白 → 日光黄 → 珊瑚橙 → 桃红。它是「按住说话」按钮、能量指示，也是大屏的中心。时段只换背景和辅色，太阳不变。
光的做法 · 每一个太阳都是六层
环境泛光 blur 80 → 光晕 blur 30 → 红 / 蓝色散两圈错位 3 px → 核心渐变（边缘 7% 羽化，不留硬边）→ 发丝日冕环 0.8 px → 地平线下倒影（镜像 + 横向条纹 + 渐隐遮罩）。整页再叠 30% 颗粒和暗角。实现时用 canvas 一次画完，不用 DOM 模糊。
02 · 六个空间母题 → 六个交互
升起 RISING
按住说话
太阳就是麦克风按钮。按住时它从地平线升起、变亮；松手后停在你说话的能量高度。手势「举手」直接推它升高。
映射 REFLECT
音轨光带
每条音轨是水面上的一道光带：地平线上是波形，线下是它的倒影。倒影透明度 = 混响量，所以「更多混响」看得见。
共振 RESONATE
节拍光环
日冕光环按拍子向外扩散，来自 MAÑANA 的十二芒星图腾。鼓越密，环越多；drop 时全部环同时炸开一次。
悬浮 FLOAT
一句话 chips
指令 chips 是半透明彩色亚克力片，浮在磨砂玻璃面板上。点一下就生效，不需要再按发送。被点中的那片亮起当前时段的辅色。
弥散 DIFFUSE
背景光晕
背景是胶片颗粒上的两团漏光，位置和颜色由当前风格与能量决定：techno 偏电光蓝，lo-fi 偏金橙。不用任何插图，只有光。
融合 MERGE
多人共创
每个扫码进来的人是一团有颜色的光。当两条光带同时在响，它们的颜色在地平线下交融，大屏上看得到「谁和谁在一起玩」。

05 · 声光电的规则
声 → 光
母线 RMS 推太阳亮度，每轨频谱推各自光带高度，鼓的 onset 触发一圈日冕。不用任何随机动画，所有动的东西都有声音来源。
手 → 声
手势只写四个宏，不经过 AI：举手 = 滤波，张合 = 能量，双手距离 = 空间，握拳两秒 = DROP。大屏角落画骨架，让人看到自己被识别。
话 → 代码 → 声
这一条是慢通道，所以要把「等」变成戏：先大字打出听到的话，再逐行点亮改动的代码，最后一句中文说明。三步各有声音提示。
电 → 现场
时段色由真实时钟驱动，10.23 到 25 三天从白天播到夜晚。可选：把太阳亮度经 OSC 或 DMX 推给展台灯带，屏幕上升起的太阳，展台上也亮。
